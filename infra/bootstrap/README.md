Long-lived AWS resources, applied once and kept: the OpenTofu state bucket, the ECR repositories (the monolith, the gateway and, from s4-l09, Payments) and the CodeArtifact repository. It also holds the GitHub OIDC provider, the deploy roles (one for the shared layer and the monolith, one for Payments, each set as a repository variable: `AWS_DEPLOY_ROLE_ARN` and `AWS_PAYMENTS_DEPLOY_ROLE_ARN`), and the task boundary: the most any role the environment creates may do.
